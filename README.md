# مسبحتي — Tasbeeh Counter

> عداد تسبيح رقمي عربي مع أهداف 33 و100، واختيارات متعددة للأذكار.

A tiny, standalone Python desktop project. **Only three repository files**: `main.py`, `README.md`, and `requirements.txt`.

## Features

- عداد مستقل لكل ذكر
- أهداف 33 أو 100 مع شريط تقدم
- زر +1 أو مفتاح المسافة للعد
- تراجع وتصفير للذكر الحالي

## Requirements

- Python **3.10+**
- Tkinter (usually included with Python on Windows)

No third-party packages required. Tkinter ships with most Python installations (including Windows Python).

## Run

```bash
python main.py
```

On Windows, `py main.py` also works when the Python launcher is installed.

## How to use

اختر الذكر واضغط **+1 تسبيحة** أو مفتاح **المسافة**. يمكنك تغيير الهدف بين 33 و100. الأعداد لا تُحفظ بعد إغلاق البرنامج.
